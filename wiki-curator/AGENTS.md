## 2. 认知网络维护与工序调度指针 (Context Pointer)

> [!IMPORTANT]
> **工序委托契约**：所有文献摄取、提炼要点、双时钟 Frontmatter 铸造、超长分治漏斗、靶向查词双链铸模、三态认识论对齐（模式 A/B/C）、原子提交与能耗看板，**必须严格遵循并调用 `wiki-curator` skill**。

当用户提出以下意图时，必须激活并执行 `wiki-curator` skill：
- 摄取 `raw/` 中的新资料或新论文；
- 检查或推进未完成的门禁队列；
- 演进、对齐或维护 `wiki/` 知识卡片网络（包括幽灵雷达扫描与批量孵化核心主题）；
- 跨文献横向对比、跨学科映射与前沿方案推演（合成洞察沙箱 `wiki/insights/`）；
- 整理与合流术语词表或执行账本提交。

## 3. 全局不可逾越之机器红线

1. **物理范围边界**：摄取资料仅限 `raw/` 根目录下的直接物理文件，`raw/` 下的所有子文件夹（如 `raw/fixtures/` 等）彻底忽略，严禁越界处理。
2. **工具路由边界**：常规单篇资料阅读，唯一合法读取工具为 `view_file`，绝对严禁调用 `slice_raw.py` 或终端脚本读文件。
3. **权威标准门禁**：`L6_informal` 非正式资料一票否决，绝对禁止作为事实标准出处；机理类主题标准字段强制填 `null`。
4. **历史范式保护**：严禁用早年文献推翻晚年成熟标准；数学公理与经典算法奠基具备永久真值。
5. **人类专属手记**：卡片中的 `## 4. 个人思考与实战手记` **绝对禁读、禁写、禁改、禁删**。
6. **严禁命令探测**：🚫 **绝对禁止调用任何 `--help` 命令探测！**
7. **工作区写盘约束**：向工作区（`wiki/`、`.scratch/` 等）创建文件时，🚫 **绝对严禁携带 `ArtifactMetadata` 参数**。
8. **测试流水线隔离**：`run_tests.py` 仅限用于系统架构/脚本代码迭代时的一键回归验证；日常单篇资料摄取主流程中绝对严禁调用。
9. **脚本源码绝对禁窥（Zero Source Inspection）**：🚫 **绝对严禁调用 `view_file` 或检索工具阅读/翻看任何底层脚本源码（包括 `gatekeeper.py`、`slice_raw.py`、`scan_ghosts.py` 等）！所有底层脚本必须严格作为“确定性黑盒 CLI 接口”直接传参调用。**
10. **合成草稿沙箱隔离**：所有检索、雷达与驾驶舱严格排除 `wiki/insights/` 中处于 `status: draft` 的页面，严禁未验证假说污染底层知识网络。
11. **正向演进合法授权**：除 `## 4. 个人思考与实战手记` 属于人类专属神圣领地绝对禁动外，卡片中的 `## 2. 理论流变与共识演进时序表` 与 `## 5. 衍生研讨与前沿反常` 属于合法知识织网演进责任区，必须在符合认识论时序时执行综合。
