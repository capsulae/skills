## 3. 全局不可逾越之机器红线

1. **物理范围边界**：摄取资料仅限 `raw/` 根目录下的直接物理文件，`raw/` 下的所有子文件夹（如 `raw/fixtures/` 等）彻底忽略，严禁越界处理。
2. **工具路由边界**：常规单篇资料阅读，唯一合法读取工具为 `view_file`，绝对严禁调用 `slice_raw.py` 或终端脚本读文件。
3. **权威标准门禁**：`L6_informal` 非正式资料一票否决，绝对禁止作为事实标准出处；机理类主题标准字段强制填 `null`。
4. **历史范式保护**：严禁用早年文献推翻晚年成熟标准；数学公理与经典算法奠基具备永久真值。
5. **人类专属手记**：卡片中的 `## 4. 个人思考与实战手记` **绝对禁读、禁写、禁改、禁删**；查阅存量卡片时调用 `view_file` 必须利用 `EndLine` 参数显式截断在手记标题之前，物理阻断手记进入上下文。
6. **严禁命令探测**：🚫 **绝对禁止调用任何 `--help` 命令探测！**
7. **工作区写盘约束**：向工作区（`wiki/`、`.scratch/` 等）创建文件时，🚫 **绝对严禁携带 `ArtifactMetadata` 参数**。
8. **测试流水线隔离**：`run_tests.py` 仅限用于系统架构/脚本代码迭代时的一键回归验证；日常单篇资料摄取主流程中绝对严禁调用。
9. **脚本源码绝对禁窥**：🚫 **绝对严禁调用 `view_file` 或检索工具阅读/翻看任何底层脚本源码（包括 `gatekeeper.py`、`slice_raw.py`、`scan_ghosts.py` 等）；所有底层脚本必须严格作为确定性黑盒 CLI 接口直接传参调用。**
10. **合成沙箱硬隔离**：检索、雷达与驾驶舱严格排除 `wiki/insights/` 中处于 `status: draft` 的页面；全库正式卡片（包括主题卡与文献卡）**绝对严禁反向引用处于 draft 状态的草稿**，仅在人类审阅标记为 `verified` 后方可连线。
11. **正向演进合法授权**：除 `## 4. 个人思考与实战手记` 属于人类专属神圣领地绝对禁动外，`## 2. 理论流变与共识演进时序表（含反常缓冲池）` 与 `## 3. 关联出处与网络` 属于合法知识织网演进责任区，按认识论时序综合。
12. **暂存状态免死保护**：`.scratch/` 下的 `terms.json` 与 `log_entry.md` 属于系统状态链路文件，🚫 **严禁执行批量清空或直接物理删除！**
13. **标准查词唯一入口**：严禁在终端手写临时 Python 检索脚本或全局 grep 扫盘；全库受控词表与别名消歧唯一合法标准入口为 `python .scripts/gatekeeper.py query-terms`。
